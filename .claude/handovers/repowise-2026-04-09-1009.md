## Key Decisions Made
- **Dropped repomix** — it's a stateless packing tool (dump repo to single file for LLM context). Different problem domain entirely. Mature project (3,658 commits, award-nominated) but not what we need
- **Final tool stack:**
  1. **ChunkHound** — semantic code search & discovery (local embeddings, DuckDB, MCP)
  2. **Repowise** — understand & document (graph intelligence, wiki, decisions, ownership, MCP)
- **Repomix is complementary, not competing** — could still be useful for one-shot LLM context dumps, but not worth investing contributor effort vs the other two
- **Repowise has cleaner language extension model** than repomix — one `.scm` file + one `LanguageConfig` entry, zero language-specific code. Repomix needs TS query + optional ParseStrategy class + multi-file registration
- **Repomix uses WASM tree-sitter** (cross-platform but heavier install); repowise uses native bindings (faster, lighter)
